# CMDB — план реализации MVP

Статус: черновик · 2026-11-08 · основа: [requirements.md](requirements.md) v0.2, [scenarios.md](scenarios.md)

## 1. Как читать план

- Работа разбита на **этапы** (E0–E9); внутри этапа — **задачи** с идентификаторами `E<этап>.<номер>`.
- Каждая задача = одна задача Jira (проект CMDB) = один или несколько коммитов с ключом `CMDB-N`.
  В колонке «Jira» — ключ, если задача уже заведена; `—` значит, что её заводят при старте работы.
- **Размер** — оценка трудозатрат с агентом: S — до пары часов, M — около дня, L — 2–3 дня.
- **Зависит** — задачи, без которых эту начинать нельзя. Остальные можно вести параллельно.
- Критерий «готово» для любой задачи общий (раздел 3); у этапа добавляется собственный.

## 3. Общий критерий «готово» для задачи

1. Реализация соответствует нужным FR/NFR; номера указаны в коде (`# TODO(FR-N)` убран или добавлен осознанно).
2. Правила из [AGENTS.md](../AGENTS.md) не нарушены: аудит в той же транзакции, мягкое удаление,
   `Depends(require(Role.X))` на каждом эндпоинте, проверка перечня УЗ в сервисе, async-БД.
3. Тесты: unit + интеграционные на реальной PostgreSQL; `pytest`, `ruff check .`, `ruff format --check .` зелёные.
4. Для задач фронтенда — `npm run build` и e2e (skill `e2e-before-commit`) зелёные.
5. Миграции — только новой ревизией, применённые не редактируются.
6. Коммит с ключом Jira; после коммита комментарий в задаче; при закрытии — итоговое резюме.

## 4. Риски

| Риск | Что делаем |
|------|------------|
| Производительность графа и списка на 20 000 CI | Замер раньше конца этапа: E4.4 сразу после E4.1; индексы закладываем в E1 и E2.10 |
| Сложность прав «роль + перечень УЗ» | Одна проверка в сервисе (E2.3), тесты прав — на каждом виде записи |
| Расхождение схемы БД и требований при росте | Первая миграция — одним пакетом (E1.5); дальше только новые ревизии |
| Шум сетевых правил в анализе влияния (вопрос 5) | Решаем после E4.2 на реальных данных, фильтры — отдельной задачей |
| Фронтенд упирается в готовность API | Типы из OpenAPI; экран начинают после эндпоинта, не раньше |
