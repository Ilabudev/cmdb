# Журнал изменений

Хронология значимых изменений проекта: новые записи сверху. Источник — история git и задачи Jira
(проект CMDB). Каждая запись: задача, коммит, что и зачем изменено.

## Как вести журнал

- Запись добавляется вместе с коммитом, который вносит значимое изменение (код, документы,
  конфигурация агента). Мелкие правки опечаток не фиксируются.
- Формат записи: `CMDB-N` · хеш коммита · суть изменения. Решения и причины — одной фразой.
- Требования и принятые решения ведутся в [requirements.md](requirements.md), порядок работ — в
  [plan.md](plan.md); здесь только то, что уже сделано.
